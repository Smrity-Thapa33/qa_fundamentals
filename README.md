# 🧪 QA Fundamentals

A structured repository for learning and practicing Manual Software Testing concepts, test design techniques, test cases, and bug reporting.

This repository includes practical QA documentation created using the JPetStore demo application and Swag Labs SauceDemo application along with core software testing concepts.

- Test Scenarios
- Test Cases
