# 🐞 SauceDemo Bug Reports

This folder contains manually created bug reports and defect tracking documents for the Sauce Labs SauceDemo application.

The reports focus on identifying functional issues, UI inconsistencies, validation problems, and unusual user interaction behaviors during testing.

## 📂 Contents

- Individual bug report files (`BR-xxx.md`)
- Special user behavior and edge case scenarios
- `Bug-Tracking-Sheet.xlsx` for defect tracking and management

## 🛠 Tested Application

Application: [SauceDemo](https://www.saucedemo.com)

## 📌 Focus Areas

- Login validation
- Cart functionality
- UI/UX behavior
- Error handling
- Boundary and negative testing
- User behavior scenarios

## 🎯 Learning Objectives

This section was created to practice and demonstrate:

- Writing clear and structured bug reports
- Documenting reproducible defects
- Understanding severity and priority
- Tracking defects effectively
- Improving analytical and observation skills in QA

## 🧪 Sample Bug Report Structure

Each report generally includes:

- Bug ID
- Title
- Environment
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity/Priority
- Status
