# ⚙️ Special User Behavior in SauceDemo

The application includes predefined users designed to simulate specific testing scenarios:

- **locked_out_user :**  Cannot login (intentional restriction)  
- **problem_user :**  Displays UI and functional inconsistencies 
- **performance_glitch_user :**  Simulates slow performance  
- **error_user :**  Generates system errors  

## 📌 Note
The issues observed with these users are **intentional and part of the application design**.  
They are used for testing purposes and should not be considered actual defects.

## 🎯 Purpose
These users help testers:
- Identify edge cases  
- Test error handling  
- Evaluate system robustness
