# 🧪 QA Fundamentals

A structured repository documenting my **manual software testing** learning journey — covering core QA concepts, test design techniques, real test cases, bug reports, and testing analysis using industry-standard documentation practices.

Practical testing applied to **JPetStore** and **SauceDemo (Swag Labs)** demo applications.

---

## 📚 Topics Covered

| # | Topic | Description |
|---|---|---|
| 01 | **Introduction to QA** | What is QA, QC, and Testing — roles and differences |
| 02 | **SDLC & STLC** | Software Development & Testing Life Cycle phases |
| 03 | **SDLC Models** | Waterfall, Agile, V-Model, Spiral and when to use them |
| 04 | **Types of Testing** | Functional, Non-functional, Black box, White box and more |
| 05 | **Test Design** | Test scenarios, test cases, and Excel-based documentation |
| 06 | **Bug Reports** | Structured bug reports with severity, priority & screenshots |
| 07 | **Test Plan** | Scope, objectives, approach, entry & exit criteria |
| 08 | **Exploratory Testing** | Unscripted session on SauceDemo — charter, notes & findings |
| 09 | **Regression Testing** | Risk-based regression suite (15 TCs selected from 33) |
| 10 | **Test Metrics** | Pass/fail rates, defect density, severity breakdown & quality verdict |
